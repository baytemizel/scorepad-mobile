# ScorePad 1.0.2 — What's New

Store copy for the Play Console and App Store Connect "What's New" fields.
Kept under 500 characters so the same text fits both (Play's limit).

## English

Fixes to how matches are scored and remembered:

• Ending a volleyball, tennis or table tennis match early no longer reports a draw — the side ahead wins.
• Match History and the summary now lead with the set score (2–0) instead of the last set's points.
• Closing the deciding set with Next now ends the match instead of opening a set that can't be played.
• Table tennis now starts each game with the right player serving.
• Handball is fully translated.

## Türkçe

Skor tutma ve kayıt tarafında düzeltmeler:

• Voleybol, tenis ve masa tenisi maçlarını erken bitirmek artık "berabere" yazmıyor — önde olan taraf kazanıyor.
• Maç Geçmişi ve özet ekranı artık son setin sayıları yerine set skorunu (2–0) gösteriyor.
• Kararlaştıran seti "Sonraki" ile kapatmak maçı bitiriyor; oynanamayacak bir set açılmıyor.
• Masa tenisinde her sete doğru oyuncunun servisiyle başlanıyor.
• Hentbol tamamen çevrildi.
