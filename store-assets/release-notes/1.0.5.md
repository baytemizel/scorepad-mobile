# ScorePad 1.0.5 — What's New

Store copy for the Play Console and App Store Connect "What's New" fields.
Kept under 500 characters so the same text fits both (Play's limit).

## English

• New back button on the scoreboard. Leaving a match in progress asks first, so a score is never lost by accident.
• Turning your iPhone now switches the scoreboard to landscape, and the rotate button keeps the orientation you pick.
• Bigger scoring buttons in portrait that use the whole screen.
• Buttons no longer sit on the navigation bar.
• A cleaner splash screen on Android.

## Türkçe

• Skor ekranına geri butonu eklendi. Devam eden bir maçtan çıkarken onay isteniyor, skor yanlışlıkla silinmiyor.
